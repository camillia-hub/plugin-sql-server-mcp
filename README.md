# SQL Server MCP

Queries a Microsoft SQL Server database. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/mcp-mssql

Installs from the Camillia hub as `sql-server-mcp-e45cb6`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
